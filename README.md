# Ignition-profile-unlocked
Profile file for Ignition DOS game by UDS (1997) with all cars, tracks and difficulty levels unlocked.

Note: This file is for the DOS version of the game.

Usage: Replace (and backup) your original IGN_DOS.BTZ file in the root of IGNITION directory with the one provided in this repository. To change the name shown in the Best Times open the file with an hex editor and replace all occurrences of FLO by whatever you want (3 characters only).
